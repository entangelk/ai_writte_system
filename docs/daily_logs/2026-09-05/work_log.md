  **D8-7 G1=C 가 배포 서버에서도 성립함을 처음으로 실증**했다.
- 그러나 `application`·`frontend` 는 `0.0.0.0` 게시라 **nginx 우회 경로가 LAN 에 열려 있다**.
- **이 서버는 다른 프로젝트와 공유한다** — 타 프로젝트의 Mongo 2대·Redis 1대·공용 nginx 가 전부
  `0.0.0.0` 게시. HANDOFF 가 오래 경고한 *"그 포트는 다른 프로젝트 것"* 함정의 배포 서버판이다.
- **`ufw` 는 active 지만 Docker 게시 포트는 ufw 를 우회한다**(DOCKER 체인이 먼저 평가된다).
  다른 머신에서 앱·프론트·타 프로젝트 저장소 포트에 **실제로 도달**했고 443·2019 는 무응답이었다.

### 세션 5 정정 — S-7 심각도를 내렸다 (오너 반문이 옳았다)

오너 반문: *"토큰 값은 서버 내 있어야 하는거 아냐? 내 서버에 접근하지 못하면 못보는 값인거잖아
그치? 그러면 회전 한다해도 동일한 위험일텐데"*. **맞다 — 내가 과장했다.** 실측으로 다시 재고
HANDOFF S-7 을 고쳤다.

**실측(2026-09-05)**:
- `/proc/<pid>/cmdline` = `-r--r--r--`(0444) · `/proc/<pid>/environ` = `-r--------`(0400).
  **메커니즘 자체는 사실이다** — 인자는 파일·env 보다 넓게 읽힌다.
- **그러나 이 호스트의 로그인 계정은 `uid 1000` 하나뿐**이고 cloudflared 는 root 로 돈다.
  타 프로젝트는 전부 컨테이너라 호스트 프로세스가 root — **탈출 시나리오에서는 인자든 env 든
  차이가 없다.** 내가 *"아무 로컬 사용자나"* 라고 쓴 것은 다중 사용자를 함의했는데 그렇지 않다.
- 남는 실질 차이는 둘뿐이다: **uid 1000 으로 도는 무언가**(개발 도구·스크립트·SSH 로 붙은 에이전트
  — 실제로 이번에 내가 비-root 로 읽었다)와 **`ps` 출력이 밖으로 새는 경로**(로그·모니터링·덤프).
- **심각도 LOW 로 내리고 Phase S 순서에서 맨 앞 → 맨 뒤로 옮겼다.**

**회전 논리도 갈라 적었다**: 회전은 저장 방식과 **다른 문제**를 푼다 — *이 값이 서버 밖으로
나갔는가*. 이번 점검에서 세션 출력에 남은 것이 유일한 근거이며, **그 기록을 신뢰하면 회전은
선택**이다. **회전만 하고 인자를 그대로 두면 새 값이 같은 자리에 놓인다**는 것이 오너 반문의 핵심이고
그대로 맞다.

**env 관리 가능 여부(오너 질문)**: `cloudflared --help` 실측 — `--token` 이 `$TUNNEL_TOKEN` 을,
`--token-file` 이 `$TUNNEL_TOKEN_FILE` 을 **네이티브로 읽는다.** 권고는 `0600` 파일 + `--token-file`
또는 systemd `EnvironmentFile=`(0600). **★ 함정: systemd `Environment=` 에 값을 직접 적으면
`systemctl show` 로 드러난다** — `EnvironmentFile` 이어야 한다.

**교훈**: 보안 발견을 옮길 때 *"누가 읽을 수 있나"* 를 **그 호스트의 실제 계정 구성으로 확인하지
않고** 일반론(*"아무 로컬 사용자나"*)으로 적으면 심각도가 부풀려진다. 오너가 반문하지 않았으면
Phase S 맨 앞에 잘못된 우선순위가 남을 뻔했다.

- **축 = C(앱 IP축 + XFF 신뢰 정책 확립).** 오너가 구현자 추천(B, 전역 비용 상한)을 **택하지 않았다.**

  되지 않는다). 즉 그 추천의 근거는 사실이 아니라 **모르는 상태**였다. 이 결정으로 2026-08-22 의

- **터널 경로는 대시보드가 아니라 서버에서 직접 확인**(오너가 읽기 전용 접근을 열어 줬다). 세션 5는

- 계약 literal 은 브리프가 B 전제로 제안했던 값을 **IP당** 으로 옮겨 채택했다(시간당 5 · pending 200 ·

- 원격 확인은 **읽기 전용**이었다 — `docker ps`·`docker inspect`·`docker logs`·설정 파일 `cat`·
  공개 오리진 `curl`(GET). 타 프로젝트 서비스에 쓰기 명령을 보내지 않았다.
- 민감정보: 주소·계정명·키 경로·도메인·토큰을 저장소 문서에 **0건** 기록(역할 별칭만).
