# dogfood 체크리스트 (GATE-1 착수 — 2026-08-23)

> 오너가 직접 쓰면서 보는 것들의 목록. 개발 문서가 아니라 **사용 설명서 + 관찰 노트**다.
> 무엇을 "이상하다"고 느끼셨는지가 이 프로젝트에서 가장 귀한 데이터다 — 정리된 형식이
> 아니어도 됩니다(아래 §6 포맷만 지키시면 제가 재현·추적합니다).

---

## 1. 시작 (한 번만)

- [ ] **배포 서버(도메인)** 접속 → `owner-account` 로그인 — 임시 비밀번호는 채팅으로 전달받은 값
      (첫 로그인에서 새 비밀번호 교체를 요구합니다, 12자 이상)
- [ ] 알파(`http://localhost:5520`)도 같은 계정이 **따로** 있습니다 — 개발 확인용, 배포 서버와 데이터가 다릅니다
- [ ] 첫 프로젝트 하나 만들어 보기(이름 아무거나)

**주의**: 로그인이 안 되면 ① 임시 비밀번호 복사 공백 ② 이미 교체하셨는지부터 확인 —
5번 실패하면 5분 잠금이 걸립니다(장애가 아니라 방어입니다).

## 2. 매일 쓰면서 보는 것 — 이게 dogfood 본체

정상 흐름: **원문 등록 → 분석(후보 검토) → 승격 → 이어쓰기(생성·수정·게이트) → 저장·내보내기**

| 단계 | 보시는 것 | "좋다"의 기준 |
|---|---|---|
| 원문 등록 | 문장 몇 개 넣고 저장 | 저장 후 화면에 그대로 보임 |
| 분석 | 분석 실행 → 후보 목록 | 내 글에서 나온 것 같은 인물·사건·의문이 뽑히는지, 근거(원문 위치)가 맞는지 |
| 후보 검토 | 승인/거절/수정 | 내가 고른 것만 기억에 들어가는지 |
| 이어쓰기 | 다음 장면 생성 요청 | **설정과 어긋나지 않는지** — 죽은 인물이 나오거나 말투가 틀리면 그대로 기록해 주세요 |
| 수정·게이트 | 수정 요청, 게이트 지적 | 지적이 실제 문제를 짚는지(모호한 지적 반복도 기록 대상) |
| 저장·내보내기 | 최종 본 저장, txt/markdown | 내보낸 파일이 화면과 같은지 |

## 3. 즉시 알려주시면 좋은 것 (쓰다가 마주치면)

- 빈 화면·빈 생성 결과(내용이 아예 없음)
- 저장했는데 안 보임 / 지웠는데 다시 생김
- 로그인 직후 다시 로그인 화면으로 튕김
- 같은 요청이 두 번 처리된 것 같을 때
- 숫자가 이상할 때(횟수·버전·날짜)

이런 것들은 **기다리지 말고 그날 전달** — 대부분 재현이 되면 바로 고칩니다.

## 4. 모아서 기록해 주시는 것 (품질 개선·결정 재료)

이 카테고리가 쌓이면 미뤄둔 두 결정(extractor 실패 기록 방식·loop 게이트 노출)을 판단할 수 있습니다:

- **후보가 이상하게 나오고 다시 시도되는 빈도** — 한 번에 깔끔히 나오는지, 재시도가 잦은지
- **게이트가 거절하는 사유가 주로 뭔지** — 말이 안 되는 거절이 반복되는지
- **검색이 엉뚱한 기억을 주는지** — 분명 쓴 내용인데 안 나오거나, 관련 없는 게 나오거나
- **생성 속도 체감** — 답답하다고 느낀 순간(어느 단계였는지)

## 5. 관측 화면 (주 1회 정도 보시면 됩니다)

프로젝트 화면의 **관측(observability)** 탭:

- **성공률·실패(에러) 분포** — provider_error가 꾸준히 보이면 외부 API 문제(제가 봅니다)
- **repair 빈도** — 같은 요청에 기록이 2건으로 보이는 것이 "재시도 1회"입니다 (실패가 아니라 회수입니다)
- **토큰 사용량** — 글 쓸 때마다 얼마나 나가는지 감

**알려진 공백(오류 아님)**: 수정 loop **안쪽**의 게이트 판정은 집계에 안 잡힙니다(독립 게이트 호출만
점수가 남음). loop 관측의 숫자가 전체가 아니라는 것만 알고 계시면 됩니다.

## 7. 운영 참고

- 오너 계정(`owner-account`)은 **요청 무제한**입니다 — quota에 안 걸립니다. 일반 회원 관점의
  quota 화면을 보시려면 가입(승인제)→ 승인 → `/me` 화면 순서로 별도 계정을 만드시면 됩니다.
- 외부 API(구글)는 무료층 한도가 있습니다 — 하루에 많이 쓰면 저녁쯤 실패가 늘 수 있습니다
  (키 5개가 같은 프로젝트면 한도가 곱해지지 않을 수 있음 — 알려진 캐비애트).
- **402/429 같은 "거부"는 장애가 아니라 시행입니다** — 다만 무제한 계정으로 나오면 그건 버그입니다.
